# 🎬 YouTube Content Factory

Автоматическая фабрика контента для YouTube с AI-генерацией скриптов, озвучкой и видео.

## 🚀 Возможности

- ✅ **Автоматический анализ ниш** — работает даже без API-ключей (офлайн-данные по нишам 2026)
- ✅ **AI-генерация сценариев** — Gemini 3.1 Flash Lite (бесплатный тариф)
- ✅ **Бесплатная озвучка** — Google TTS (онлайн) с автоматическим откатом на офлайн-движок
- ✅ **Генерация видео** — автоматический монтаж со слайдами и озвучкой
- ✅ **Минимум ручной работы** — установка и запуск в 2 команды

## 📦 Установка (2 команды)

### Mac / Linux
```bash
chmod +x setup.sh start.sh
./setup.sh
```

### Windows
Дважды кликни `setup.bat` (или запусти из командной строки).

Скрипт установки сам:
1. создаст виртуальное окружение
2. поставит все зависимости
3. создаст `.env`
4. спросит твой Gemini API-ключ (получить бесплатно: https://aistudio.google.com/app/apikey) и сразу сохранит его

YouTube API ключ **не обязателен** — без него анализ ниш работает на встроенных данных.

## 🎯 Запуск

### Mac / Linux
```bash
./start.sh            # интерактивное меню
./start.sh analyze    # только анализ ниш
./start.sh create     # создать видео (полный цикл)
```

### Windows
```
start.bat
start.bat analyze
start.bat create
```

## 📤 Публикация на GitHub (1 команда)

Сначала создай пустой репозиторий `youtube-factory` на github.com (без README), затем:
```bash
./push_to_github.sh твой-github-username
```

## 📁 Структура проекта

```
youtube-factory/
├── main.py                 # Главный файл
├── niche_analyzer.py       # Анализ ниш
├── script_generator.py     # Генерация сценариев (Gemini)
├── voice_generator.py      # Озвучка (Google TTS / офлайн)
├── video_generator.py      # Создание видео (MoviePy)
├── config.py                # Конфигурация и список ниш
├── requirements.txt         # Зависимости
├── setup.sh / setup.bat     # Установка одной командой
├── start.sh / start.bat     # Запуск
├── push_to_github.sh        # Публикация на GitHub одной командой
├── .env                     # Твои API-ключи (не публикуется — в .gitignore)
├── data/                    # Результаты (JSON с метаданными)
├── audio_output/            # Готовые аудиофайлы
└── video_output/            # Готовые видео
```

## 🔧 Технологии

- **Gemini 3.1 Flash Lite** — генерация сценариев и заголовков
- **gTTS (Google TTS)** — бесплатная озвучка
- **MoviePy + Pillow** — монтаж видео
